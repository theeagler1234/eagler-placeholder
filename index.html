What is Eaglercraft?

Eaglercraft is an unofficial project that ports older versions of Minecraft to run inside a web browser, with no installer and no Java required.

The basics

Eaglercraft takes Minecraft's Java Edition code and compiles it to JavaScript so it can run in a normal browser tab. That makes it popular on devices where installing software is difficult, such as locked-down school Chromebooks.

It was created by developers known as lax1dude and ayunami2000, and the name is a nod to the "Eagler" naming used across the project.

Eaglercraft builds have historically targeted two older Java Edition versions:

1.5.2: the original, lighter port.

1.8.8: a later port with newer gameplay, such as the combat system many players prefer for PvP.

Exact versions and features vary by build and fork.

Browsers cannot open raw game connections, so Eaglercraft multiplayer works over WebSockets. Servers run a compatible proxy or plugin that translates between browser clients and the game server.

Some versions also support peer-to-peer "LAN" style worlds using WebRTC.

Eaglercraft is not made, endorsed, or supported by Mojang or Microsoft. Because it is derived from Minecraft's code, it has faced takedown requests in the past, and availability and legality can vary.

If you enjoy the game, buying an official copy of Minecraft supports the people who make it.
